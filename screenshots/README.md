# Screenshots

This folder holds screenshots of DevPress for the main README. There are none yet: screenshots are only added when they show the real, running application with test data, never a mock-up.

## Expected files

| File | What it shows |
|---|---|
| `login.png` | Log in page (form beside the charcoal panel, desktop width) |
| `dashboard.png` | My publications after logging in |
| `publications.png` | Create publication with the live preview |
| `publication-workspace.png` | A workspace Overview with the sidebar |
| `appearance.png` | Appearance settings with the live preview |
| `editor.png` | The article editor in Document view with the formatting toolbar |
| `typewriter.png` | The Typewriter view while writing |
| `document-mode.png` | Side by side or Preview view of a formatted article |
| `published-article.png` | A published article on the publication website, with a code block |

## How to capture them

1. Run DevPress locally (see the main README) connected to a **test database**, not one with real accounts.
2. Register a test account and create a sample publication and article. Do not show real email addresses or personal data.
3. Use a desktop browser window about 1440 × 900 px at 100% zoom.
4. Capture the visible window (macOS: `Cmd + Shift + 4`, then `Space`, then click the window; Windows: `Win + Shift + S`).
5. Save as PNG with the file names above, and keep each file under about 1 MB.
6. Reference them from the README's Screenshots section, for example `![Typewriter view](screenshots/typewriter.png)`.
